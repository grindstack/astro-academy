Introduction

What is Astro Academy?

Astro Academy is a modern, web-based e-learning platform dedicated to astronomy, space science, and astrophysics education.

  • Purpose: Deliver accessible, engaging space-science education online
  • Primary Users: Students, space enthusiasts, lifelong learners
  • Platform: React.js SPA with Tailwind CSS & Framer Motion
  • Backend: Python / FastAPI with AI-powered Stellar Scanner

Key Functionalities

🌌 Course Catalogue

Browse astronomy & space-science courses

🔭 Stellar Scanner

AI-powered celestial-object classification

👤 User Auth & Dashboard

Secure registration, login, and profile

Security Testing

Security Testing Results

🔒

Password Masking

Password fields use type="password"; characters are masked on input & never exposed in the DOM or network logs.

🛡️

Route Protection

Protected routes redirect unauthenticated users to /login using React Router guards before rendering sensitive pages.

🚫

Unauthorized Access Prevention

Direct URL access to /dashboard or /admin without a valid session token is blocked server-side with 401 responses.

🧹

Input Validation & Sanitisation

All user inputs are validated on both client and server. XSS payloads and SQL-injection attempts are safely handled.

🔑

Session Handling

JWT tokens stored in httpOnly cookies; tokens expire after inactivity; logout clears session storage completely.

✅

Overall Security Assessment

Core security measures are correctly implemented. Recommended improvements: add CSRF tokens, rate-limiting on login.

Challenges & Improvements

Challenges Identified & Suggested Improvements

⚠ Challenges Found

📉
Low Performance Score (43)
Large render-blocking JS & uncompressed images reduce Lighthouse score
🔍
Incomplete SEO (82)
Missing structured data & Open Graph meta tags limit discoverability
📱
Mobile Navbar Overlap
Hero content overlaps at < 360 px viewports — requires CSS fix

🚀 Recommended Improvements

  • Performance Optimization: Code-splitting & tree-shaking to reduce JS bundle size
  • Image Compression: Convert all images to WebP format with responsive srcset
  • Lazy Loading: Add loading="lazy" to images & defer non-critical scripts
  • Better SEO: Add JSON-LD structured data, canonical URLs, Open Graph tags
  • Enhanced Security: Implement CSRF tokens and brute-force rate limiting
  • Error Handling: Add image fallbacks and graceful API timeout messages
  • Automated Testing: Integrate CI/CD pipeline with Jest + Cypress for regression tests
